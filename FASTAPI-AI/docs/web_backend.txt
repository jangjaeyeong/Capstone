# 웹 백엔드 개발자

웹 백엔드 개발자는 브라우저나 앱에서 온 요청을 서버에서 처리하고,
DB에 접근하여 데이터를 읽고 쓰는 역할을 담당한다.

## 주요 역할
- 회원가입, 로그인, 권한 처리
- 게시글 등록, 수정, 삭제
- 결제, 주문 처리, 알림 등 비즈니스 로직 구현

## 필수 스택 예시
- 언어: Java, Python, JavaScript(Node.js)
- 프레임워크: Spring Boot, Django, FastAPI, Express
- 데이터베이스: PostgreSQL, MySQL
- 기타: REST API, HTTP, Git, Docker
